Rocky Linux 9 / AlmaLinux 9 安装 Nginx（官方稳定版）

从零安装到可访问，面向生产环境的最小可用流程。

Back to Guides · Home

适用系统：Rocky Linux 9 / AlmaLinux 9

目标：使用 Nginx 官方 stable 源安装最新版稳定版本，并完成服务启动和防火墙放行。

1. 更新系统并安装基础工具

sudo dnf update -y
sudo dnf install -y dnf-utils curl ca-certificates

2. 添加 Nginx 官方 YUM 源

sudo tee /etc/yum.repos.d/nginx.repo >/dev/null <<'REPO'
[nginx-stable]
name=nginx stable repo
baseurl=http://nginx.org/packages/centos/9/$basearch/
gpgcheck=1
enabled=1
gpgkey=https://nginx.org/keys/nginx_signing.key
module_hotfixes=true
REPO

3. 安装 Nginx

sudo dnf install -y nginx
nginx -v

4. 启动并设置开机自启

sudo systemctl enable --now nginx
sudo systemctl status nginx --no-pager

5. 防火墙放行 HTTP / HTTPS

sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
sudo firewall-cmd --list-services

6. 基础可用性检查

curl -I http://127.0.0.1
sudo ss -tulpen | grep ':80'

浏览器访问 http://服务器公网IP，看到 Nginx 欢迎页即安装成功。

7. 常用管理命令

sudo nginx -t
sudo systemctl reload nginx
sudo systemctl restart nginx
sudo systemctl stop nginx

8. 重要路径

  • /etc/nginx/nginx.conf：主配置
  • /etc/nginx/conf.d/：站点配置目录
  • /usr/share/nginx/html：默认网站根目录
  • /var/log/nginx/：访问/错误日志
